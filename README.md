## Имена Secrets

Формат: `SOURCE_URL<номер-источника>_<логический-слот>`.

Например:

- `SOURCE_URL1_1` — источник №1, обычный, слот 1
- `SOURCE_URL3_2` — источник №3, обычный, слот 2
- `SOURCE_URL14_3` — источник №14, обычный, слот 3
- `SOURCE_URL21_9` — источник №21, whitelist, слот 9

Для классификации важен **последний номер после `_`**. Первый номер нужен только для твоей идентификации источника.

Один логический слот должен содержать одну URL. Всего updater принимает максимум **15 уникальных source URL**, потому что для них используются 15 отдельных Happ-профилей.

**Важно:** обычный источник не превращается целиком в whitelist. Если среди его серверов парсер распознаёт whitelist по remark/метаданным, **только этот конкретный сервер** отправляется в LTE whitelist-пул.

Старые `SOURCE_URL_1…SOURCE_URL_15` и `KEYLINE_URL_1…KEYLINE_URL_15` оставлены как fallback на переходный период.
