# VPN source report

Статистика ведётся **по каждому источнику отдельно**: **взяли → живы → в итоговом пуле**.

Последний запуск ещё не записал фактические значения.

## Правила слотов

| Слот | Назначение |
|---:|---|
| 1–8 | обычные источники |
| 9–15 | whitelist / LTE-источники |

### Имена Secrets

Формат может быть произвольным перед последним `_`:

- `SOURCE_URL1_1` — источник №1, логический слот 1;
- `SOURCE_URL15_1` — источник №15, логический слот 1;
- `SOURCE_URL20_2` — источник №20, логический слот 2;
- `SOURCE_URL_7` — обычный источник, логический слот 7;
- `SOURCE_URL_12` — whitelist / LTE-источник, логический слот 12.

**Последнее число — единственное, которое определяет слот.** Первый номер нужен только тебе, чтобы помнить, откуда взята ссылка.

Всего используется 15 логических слотов.

Обычные источники (слоты 1–8) дополнительно проверяются по текущим ключевым словам whitelist. Если найден **конкретный** сервер, подходящий под эту классификацию, в LTE-пул отправляется только он; весь источник целиком whitelist-источником не становится.

После каждого запуска таблица выше обновляется отдельно по каждому настроенному источнику. В ней показывается только:

**Взяли → Живы → В итоговом пуле**

Отдельно указывается, сколько серверов было сохранено из памяти предыдущего пула.
